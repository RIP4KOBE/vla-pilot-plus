# Task0 closed-loop sequence: proposed read protocol v1

Status: prepared for root review; actual scientific reads and the analysis script are not yet authorized by this document. This is post-outcome Dev exploration. Known motivation is N2's valid task failure and 3 guided chunks versus C0 29 and Q0 52. Those differences are not a causal result. The completed checkpoint established Q8 selection activity, not manipulation benefit. This analysis cannot change the running N2 cohort, source, scoring rule, recovery policy, thresholds or acceptance gates.

The bounded question is: when did the recorded approach guidance turn off or resume, which actual Stage/query events preceded that state, and what did the recorded commands, EEF, gripper and policy-visible keypoints do afterward? “Earlier” means fewer elapsed executed steps relative to these two complete controls. It does not mean that guidance should have remained on, that a grasp was obtained/lost, or that an alternative Stage decision would have succeeded.

A timing detail must be preserved rather than “corrected” offline: before a fresh chunk, `action_executed` is zero but `action_chunk` still holds the preceding chunk. `_get_gripper_value(action_chunk, action_executed)` therefore normally reads that preceding chunk's **first** command (`main.py:977`, `:1666`, `:2085`), not the last actual sent command or qpos. Report logged `gripper_value_used` plus logged first/last values and actual sent command history as distinct fields. Match Stage events to decisions by episode and `global_step`, not an assumed equality of `chunk_id` and collector decision ordinal: main increments chunk_id after policy selection.

## Deterministic descriptive outputs

1. Build the full observed timeline for all three episodes, retaining every decision, Stage event and actual action prefix. Segment maximal contiguous runs by actual `(stage,use_guidance,provider identity)`; report start/end executed step and chunk count, first ON-to-OFF, every later OFF-to-ON, last ON and terminal endpoint. “Approach active” additionally requires the actual provider's reviewed approach semantics, not stage number or a default keypoint. Do not select a favorite transition or discard reactivations. Join each transition to the same-step Stage event, or label its cause unresolved; a missing-provider disable is distinct from a recorded Stage reply.
2. For every action record retain EEF xyz/optional quaternion, gripper command/qpos/qvel, sparse environment reward and actual terminated/truncated/success. For each maximal run report EEF net displacement and path length, command-sign sequence and number of sign changes, and gripper qpos endpoint/range descriptively. Compute paths only across consecutive observed steps in the same reset sequence. An absent first origin or terminal partial prefix remains explicitly missing; no padding or reset observation substitution. Do not introduce “stationary,” “grasped,” “stuck,” or contact thresholds.
3. Report every recorded keypoint array at decision boundaries and same-index displacement between adjacent compatible arrays; if count, reset sequence, or supported identity continuity breaks, stop that keypoint join. This is sampling at chunk boundaries, not object motion during individual steps. Stable values cannot distinguish a stationary object from the tracker's initial-position fallback. Do not query any new adapter object pose or infer an object name from index 0. After an approach provider turns off, the previously verified keypoint index may be displayed only as an explicitly carried descriptive reference; it is not a current reward objective or a proof that the same point remains the right goal.
4. For decisions with an unambiguous existing selected projection, reuse the frozen continuous definitions: per-step projection error, endpoint error, prefix RMSE, predicted/observed displacement and t7-to-t8 change for full-eight prefixes. Target-relative progress uses a reviewed identity-bound target and the **decision-frozen** point; it is not progress relative to a contemporaneous moving object. The frozen analyzer's source-origin/cast-t0 distinction and native ULP screens remain unchanged; no new cutoff is fitted. If no valid target map is explicitly bound, retain target-independent tracking diagnostics and mark target-aware quantities Unknown. Off-guidance commands retain actual motion analysis, but their missing prediction/raw/Q8 is not reconstructed.
5. Preserve the existing selected-Q8 tradeoff witness and compare the arms descriptively by executed-step timeline and their complete guidance runs. Same initial seed/init does not make later states or decisions matched counterfactuals. No subtraction at equal global_step is a causal treatment effect, no chunk is treated as an independent trial, and no new statistical/promotion test is introduced.

A target map, if used, must be an explicitly supplied already reviewed original-code/transformed-source/path identity map with its source hashes verified. Do not use the frozen map-v2's known mismatched marshal identity as a silent match, edit a map to fit these outcomes, infer a target from a comment/name/regex, or call the provider. For N2, runtime `qd_quality_identity/target_index` is corroborating bound metadata; controls still require their own exact recorded source identity join. Missing Stage-normalized input, live object pose/contact, unique archive insertion ancestry, projector counter and unexecuted candidate outcomes stay Unknown.

The eventual minimal script takes three explicit episode roots and an optional explicit reviewed target map; it has no directory discovery or algorithm configuration writes. It produces only: `inputs-and-audit.json` (input/source hashes, admission verdicts, scope and Unknown reasons), `closed-loop-sequence.json` (per-arm full Stage/decision/actual-step/keypoint/eligible-quality records plus run summaries), and a short `comparison.md` stating observed ordering, post-OFF behavior and limitations. A compact sequential plot may be generated from these records only if needed; no new scientific reader/framework is proposed. This preparation contains no implemented reader and no newly inspected outcome rows.

Root approval of this bounded read scope precedes implementation and scientific execution. Whatever the exploratory explanation finds, current N2 dispatch and frozen cohort criteria remain unchanged.
