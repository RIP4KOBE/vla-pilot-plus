### token creation

Require all eight decoded gripper=-1 and rotations=0. Save prior observed EEF before execution plus actual decoded translation summary and full identity. ### predicted observed

Use committed, acknowledged decoded fp32 action values promoted to binary64: p[k]=0.01*sum(j=0..7,u[j,k]); d=current_observed_EEF-prior_observed_EEF in the same world frame. Sum in fixed j order and dot=sum(k=x,y,z,p[k]*d[k]) in fixed order. All inputs/intermediates finite; norm(p)>0 (no tolerance or task-specific threshold), dot(p,d)<=0 including exact zero. No projection/provider score or target displacement substitutes for physical EEF d. Audit fixed-order arithmetic including equality cases; near-zero sign differences from a different reduction are a pre-release issue, never resolved by epsilon tuning.

### boundary enter

Atomically transfer and clear previous token at entry, including ineligible entries. Evaluate once before inner search from cached observation; immutable eligibility latch belongs only to this adjacent decision.

### inner updates choice

PROPOSED_FOR_INDEPENDENT_REVIEW: latch persists through all ten existing offspring opportunities iterations0..9 within that one adjacent decision. Consume-once means once per decision, not once per candidate insertion. Each update clones its own current ordinary archive best and uses unchanged current-boundary geometry. It may insert one detour at slot15 per update; max10 per eligible decision, not ten extra candidates.

### justification

Registered trigger is the adjacent decision with N34 insertion slot/remainder lifecycle. N34 already offers each of ten updates; decision-local latch preserves that lifecycle and does not add cross-decision memory. First-update-only suppression would change duration because of CPU selection evidence. CPU evidence only establishes first insertion; ten-round implementation and prospective competition remain blockers.

### expiry rearming

Expire latch at decision finish whether candidate lost, selected or absent. A later direct observed_open_approach selected and independently full8 executed may create a new token for its own next decision. A selected N36 detour, descendant ordinary rollout, direct-close, ordinary or unknown origin must not rearm, even if bytes equal direct approach. No ancestry-based relabeling.

## Deterministic path and native arithmetic

### geometry

Copy N34 binary64 quaternion normalization and rotation order exactly: q=(x,y,z,w)/sqrt(fsum(q_i*q_i)); R rows ((1-2*(y*y+z*z),2*(x*y-z*w),2*(x*z+y*w)),(2*(x*y+z*w),1-2*(x*x+z*z),2*(y*z-x*w)),(2*(x*z-y*w),2*(y*z+x*w),1-2*(x*x+y*y))). delta=target-EEF; local[axis]=fsum(R[k][axis]*delta[k]). lower=jaw[1]+0.0005, upper=jaw[0]-0.0005. Empty gap or invalid/nonfinite geometry is no-op under existing N34 validation, not expanded capture.

### direct close priority

### error

Outside box: jaw center local c=(0,(lower+upper)/2,-0.0036), world_center[k]=fsum(R[k][axis]*c[axis]); e[k]=delta[k]-world_center[k]. Use current observations only.

### deterministic path

For eligible boundary and finite nonzero e, choose minimum abs(e[k]/norm(e)) axis with exact ties x then y then z. Implement comparison with abs(e[k]) as in accepted feasibility arithmetic (common positive normalization preserves ordering); do not round normalized components before tie comparison. Unit axis j; cross=e cross axis_j in right-handed xyz; t=cross/hypot(cross). a[k]=max(-1,min(1,e[k]/(8*0.01))); b[k]=t[k]*hypot(a). j=0..3 translation clip(a+b,-1,1); j=4..7 clip(a-b,-1,1). All8 rotations0 and gripper-1. Binary64 geometry/path until a single conversion of commands to template native dtype. Zero/nonfinite e/cross or invalid current geometry fails closed and is recorded; no arbitrary alternate direction.

### encoding

Native template shape(64,128), dtype bfloat16 or float32, actual deployment dtype preserved (bound records bf16). Clone template; encode normalized deltas to columns[39,40,41], rotations[42,43,44], gripper10 for rows0:8 only using encode_libero_prefix. No affine normalization, absolute pose or ortho6d. Preserve rows8:64 and all other prefix columns byte-for-byte including signed zeros. Reject unsupported dtype/shape/mask/nonfinite action contracts.

### decode

Deployed selected native plan passes policy native-to-fp32 boundary, first particle and first8 rows, gather[39,40,41,42,43,44,10] into fp32; negative gripper->-1, otherwise+1. Require actual decode equal native-command-cast-to-fp32 bytes. Audit downstream actuator clipping and step-return action bytes, not only intended commands.

### clipping caveat

Record preclip binary64 halves, clipped components, once-cast native values, decoded sums and proxy endpoints. Component clipping plus quantization can alter both tangent cancellation and endpoint. No endpoint equality, collision avoidance, obstacle/contact existence or grasp relevance claimed. Physical path must be measured prospectively.

### fallback and noop

Ineligible N36 uses unchanged N34 direct-open/direct-close logic. Invalid geometry keeps N34 fail-closed/no-op semantics. If candidate equals template native bytes, report no_native_change and leave ordinary slot15; no forced nonidentity or insertion. Detour remains origin-distinct even when alias bytes equal another origin.

### insertion

Preserve other15 actual current-round candidate bytes. No extra direct competitor forcibly added or removed elsewhere; current archive and naturally generated direct alternatives remain ordinary competitors.

### competition
