# N26 后续机制复查备忘（仅静态分析，非新实验协议）

2026-10-01，N26 Dev 正在按冻结版本 6026794cd5d52f3a5054bf2704ebb3c516f9f47e 执行。本文只使用已经审阅的源代码、已关闭的 N25 描述性总结与既有研究结论；不使用 N26 尚未完成的分组结果选择新方法，不授权源代码修改、额外计算、验证或正式集。

当前 N26 检验的是一个明确的问题：在 sample-prediction 调度器下，用同一次前向的干净预测计算 RBF 梯度，是否比从 noisy_sample 计算梯度更有用。它没有同时改变梯度归一化、scale=20、执行前缀、QD 排序或搜索计算量。运行中的对照和候选均保持原协议。

## 现有证据的边界

- N25 的逻辑开发结果为 C0 1/7、Q0 0/7、N23 0/7、N25 1/7，触发数值无望门；原工程无效尝试及其费用仍保留。
- N25 的已关闭描述性总结在四个已审计候选任务中观察到 703 次 RBF 调用、28.81% 的输入平移分量在裁剪区外，没有整个调用梯度为零。该总结说明裁剪机制活跃，不能证明抓取获益或梯度方向正确。
- 记录中的 update_operand 是加法操作数。它不是 BF16 加法后精确输出差，也不是调度器输出、裁剪后的执行动作差或真实机器人位移。
- N26 第一 guided 决策的有限原生 witness 由同一个计账 worker 验证。现有协议禁止外部张量重放；本备忘不扩大该读取范围。

## 静态代码指出但尚未实证的问题

共享 RBF helper 对整个群体梯度做一次全局 L2 归一化，再以负号和 scale=20 加到模型预测的平移坐标。梯度支撑最多为 16 个候选 × 8 步 × 3 个分量，共 384 个分量。忽略舍入且非零梯度完全位于这些坐标时，名义操作数 RMS 为 20/sqrt(384)，约 1.02 个归一化动作单位。执行动作裁剪边界是 ±1；这给出了检查步幅是否超出局部有效区域的理由，但不是实际越界频率或失效因果证据。群体归一化还可能让少数接近重合的候选支配步幅。

strict-interior 导数只确保裁剪区外及边界上的输入梯度为零；它没有限制一个区内输入在加入操作数后是否越过边界。对 noisy_sample 求导时，这个区内条件还不直接约束实际被更新的 clean model_output；N26 正在隔离后一个输入语义问题。

逆距离势能、代理几何分散、抓取进展是不同指标。仅凭更大的分散、更多非零梯度或更高代理质量，不足以宣称下一种优化值得上 GPU。旧研究的全局 RBF 权重扫描和扩大搜索量已有弱结果，不重复没有新增证据的邻近参数扫描。

## N26 关闭后的条件分支

1. 若完整开发达到冻结晋级门，优先执行独立验证；不为新颖性另改算法。
2. 若有效淘汰，先用既有、允许读取的逐调用标量元数据比较 N25/N26 的零梯度、裁剪比例与归一化强度，并完整保留任务 gain/loss。其用途是判断输入修正是否改变了假定的中间机制，不可推断未执行候选的物理效果。
3. 若机制变化明确而任务仍无改善，步幅/局部可行性约束可列为待证伪方向；须先补充能区分“操作数很大”与“实际动作被有害改变”的部署可获得测量。尚无此证据时不直接宣布 trust region 或更小 scale 是优先胜出方法。
4. 若计算输入修正并未产生预期机制变化，检查测量覆盖与假设，避免堆叠新开关。若工程无效，保留原结论和费用，先定位原错误，不把它当科学失败或自动重跑。

任何后继候选仍须是一个主要改动、固定 176 次候选评价/11 批评分、同轮对照、部署可获得信息、完整负结果披露。Stage 仅通过当前 Codex 登录账号调用；Poe 或其他账号/服务回退均不允许。目标尚未达成。
