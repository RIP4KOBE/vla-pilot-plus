A fixed global scale sweep is still unsupported: the imbalance varies sharply between initial and later populations, suggesting a population-relative distance constraint as a distinct falsifiable mechanism.

This includes the original random noise, denoising and mask; no same-noise untreated counterfactual exists. Do not claim the model causally erased a measured fraction of mutation or that a different action would have succeeded. Next hypothesis for separate CPU design review: bound each raw diversity proposal's row norm by the current before-population centered RMS radius, then retain the existing feasible-ray bound. Use the same formula at the14 existing initial/parent calls of N28, with no new tuned coefficient or model/score call. This adapts distance to the current finite population; its spread is not calibrated uncertainty. Zero spread yields zero nonzero-operand motion with no artificial floor. Subsequent native rounding and any actual change must be audited, and only prospective matched task outcomes can establish usefulness.
