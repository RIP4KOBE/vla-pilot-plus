# Root rationale for the closed numerical diagnostic

This note precedes tensor payload access and selects no new algorithm. It supplements the frozen preparation scope/addendum.

Original accepted all-call summaries already show feasible-ray limiting on 7,179 / 8,512 N27 particle-call rows (84.3398%) and 23,248 / 25,760 N28 particle-call rows (90.2484%) in this closed cohort. Denominators are 16 times the verified call-summary count (532 and 1,610), not independent task samples. Guided-decision counts differ (28 and 115), and phases/placement differ, so these are not matched causal estimates.

A feasible-ray bound guarantees no newly exterior component but usually allows the limiting moving component to reach a box face. This static distinction is not a discovered task failure. Existing aggregate records do not say how the actually assigned delta compares with current model-generated candidate differences or whether the altered temporal structure survives subsequent denoising.

The offline diagnostic therefore estimates exact boundary transitions and displacement relative to empirical before-population spread, while retaining full cell and phase coverage. If the intervention already has small, structured effects, simple shrinkage has no new support. If it frequently overwhelms the local candidate spread or temporal pattern, an explicitly adaptive proposal-distance constraint may be a falsifiable distinct hypothesis; it still has no established task benefit and cannot be adopted from proxy improvement alone. Empirical spread is a small-sample descriptive quantity, not a calibrated uncertainty estimate. No threshold or scale is selected here, and zero spread remains explicit.

Any such proposal must distinguish itself from historical global-scale sweeps, clipping-only changes, the N27 maximal feasible ray, and N28 timing relocation; retain substantive QD and ED, fixed model/score budget, current-Codex-only Stage, and prospective matched task outcomes. No new execution follows automatically from this note.
