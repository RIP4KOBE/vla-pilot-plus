# N25 conditional CPU implementation

No online registration/admission/controller is provided. Current N24 owns the online queue. This is source preparation from3b7afa0, with N23 scientific profile and N24 rescue disabled. The two descriptor fields alone change to `actuator_clipped_eef_v1`; all original profiles are byte unchanged.

The new helper creates a temporary RBF input, replaces only first8 translation indices39/40/41 with component clamp[-1,1], and calls the original projector once per candidate, in original order. The original native0.01/cumsum/origin convention is therefore retained without touching the shared score/descriptor/decoder projector. Its strict-interior derivative is1; at exact±1 or beyond it is0. No straight-through or raw fallback. Inverse-distance potential, masking, normalization threshold/epsilon, signs, scales and schedules match absolute RBF. Default paths remain unchanged. Nonfinite or unavailable gradient raises; correctly all-zero gradient returns zero and remains a valid scientific outcome.

The new mode records native scalar summaries in the existing per-step evidence lists, including phase/iteration/timestep, shape/dtype/stride, clipping/boundary counts, pre/post normalization, masked gradient and scaled update operand. Global step/Stage bind at guided-loop closure; enclosing event/metrics bind the decision. `update_operand` is NOT measured model-output delta. These rounded scalars are not exact native arithmetic proof. Both initial and rollout are reported separately. No new tensor appears in JSON metrics.

Under the separate CPU witness authority, the first guided decision per episode records at most11 fixed slots: first active initial call and first active call of each rollout iteration0..9. No value/outcome sampling or backfill; Stage reset does not reset this budget, episode reset does. Missing recorder on the first decision does not shift capture to a later decision. Missing scheduled calls are explicit in the coverage event. Numeric caps are20KiB/call and220KiB/episode, identity metadata16KiB/call. Input is translation-only, with same-call pre-cast/cast origins, projected xyz, gradient before/after normalization, update operand and actual model-output slices immediately before/after the unchanged +=. There is no full latent dump, second origin read/projector/gradient/model call or identity probe. Recorder envelope and the later metered worker receipt must bind attempt/reset/decision/source/runtime identity; this CPU phase does not invent that future runtime evidence. Stored tensor capture strides are labeled as such, distinct from input strides or future serialization layout.

Finite new geometry does not imply useful exploration: multiple clipped paths can coincide and global normalization can concentrate unchanged total norm on fewer coordinates. No activity threshold is imposed. New-mode CPU correctness and bounded synthetic recording are established; exact CUDA replay, independent native N25 witness audit, controller profile gate, worker/source/proof bridge, whole-cohort protocol, capacity/admission and efficacy remain later reviewed work. This phase runs no real model/API/simulator/GPU and makes no task-score claim.
