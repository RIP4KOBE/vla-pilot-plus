# N6 projection accounting clarification

Frozen before online release. The N6 descriptor introduces no projector call site: it consumes the existing projection at each canonical population. A CPU integration test showed that changing archive cell occupancy can change the number of rows in pre-existing archive observer projections, even with the same 176 candidate evaluations, 11 score calls, model forward counters and canonical scoring projections. The protocol's "no additional projector" statement refers to the descriptor computation itself, not equality of all occupancy-dependent observer row counts between two different algorithms. Report total projection/model/denoising/reward calls and rows for each online cell; preserve the 176/11 hard compute gate and do not attribute data-dependent observer differences to task benefit.
