# Conditional CPU design: behavior-blind quality archive replacement

Status: design only. This is a required future attribution control, not a new candidate, online release, or change to the running N22 source. No validation/formal outcomes were used. The original execution specification section8 permits a compute-matched QD removal/replacement ablation; this design chooses an explicit replacement because the terminal selector and Stage normalization currently consume archive products.

## Scientific question and replacement

Does the promoted candidate's behavior-partitioned archive plus coverage-oriented parent allocation contribute beyond quality-only search memory at the same canonical model/reward budget? Preserve the promoted candidate's exact quality formula, raw-provider association, N5 final eligibility/choice rule, model, provider, Stage algorithm, decoder, eight-action execution, and ED/RBF/renoise settings. Replace only grid-cell competition and sparse cell allocation with a behavior-blind archive of at most16 distinct latent-action fingerprints, retained globally by effective quality. Sixteen equals the candidate grid's maximum capacity, not its variable occupied-cell count. Do not increase candidate evaluations or reuse any unscored action.

Order entries by descending native effective quality then the established stable action fingerprint; use the established first native occurrence for a duplicate with equal quality. Current-decision provenance, raw quality and action identity travel with each entry. No task/seed condition, previous-chunk state, object/contact/privileged feedback, or learned model is introduced. Reset per guided search exactly as the active archive does. Ignore all behavior descriptors for retention and allocation; optional passive recording cannot feed any decision.

For parent allocation, specify a deterministic quality-only allocation before implementation release: temperature0.1 softmax over retained native effective qualities, multiplied by16 slots, floor plus largest remainders with stable fingerprint tie break. This is an explicit replacement, not a claim that it equals historical P2 resampling. Independent audit must reconstruct qualities, ranks, deduplication, probabilities, exact slot counts and returned action/raw/effective associations. ED still performs16 initial candidates plus10 rounds of16 offspring,11 canonical score batches total.

Terminal action selection still operates on the final canonical16 offspring under the exact candidate eligibility and quality semantics. There is no archive-best execution substitution. Raw selected quality remains the Stage selected-reward input. The existing Stage spread formula is unchanged, but its reference cost array is now the quality-only retained archive; that array can differ in cardinality and distribution from the grid archive. Record this as an inherent downstream effect of the replacement, never hide it as unchanged Stage input. Do not retain a shadow grid archive whose behavior partition can still influence Stage; that would not remove the mechanism being tested. Report per-episode Stage calls and guided duration as well as176/11 compute per guided chunk.

## Implementation and reporting requirements

Implement only in an isolated worktree after choosing the concrete promoted candidate. Use a dedicated replacement mode/profile, default off; never reinterpret historical `qd_archive_mode=none` or change N22/N23's frozen scientific profile. Native evidence/audit must distinguish replacement entries from real QD cell IDs and must not falsely report QD coverage, grid parents or active behavior partition. Candidate-on native fixtures must remain bitwise identical across the integration, including Stage metadata and every dispatched action. Negative audit fixtures must detect a descriptor-dependent choice, wrong quality ordering, slot drift, duplicate/stale identity, changed raw Stage binding, or extra scoring.

Only after CPU implementation, independent audit, actual source/profile freeze and resource binding can this control be included in the single formal matrix. It is ten of the existing40 formal attempts (candidate/C0/Q0/replacement), subject to remaining formal resources; no separate development or protected rollout is authorized here. If earlier empirical calibration is scientifically necessary, it needs its own prospective Dev protocol and metered allocation, with no formal exposure. Source plumbing may be prepared earlier, but candidate science cannot change after validation.

Interpretation is limited: a difference measures this declared grid/coverage-to-quality-only replacement, including resulting Stage spread and population histories. A tie does not establish a QD contribution. Even if engineering acceptance succeeds, disclose an unsupported causal explanation. The deployed candidate itself must continue to exhibit substantive behavior discrimination, quality competition and ED parent search; the control intentionally does not satisfy that algorithm requirement.
