# Historical source archive

New development starts from `main`. This branch is a historical source snapshot, not a newly evaluated baseline.

See [manifest.json](manifest.json) and its shards for file identities; [redactions.json](redactions.json) records overlay publication redactions. Credential-like literals (including test canaries) and signed URL queries were removed from a separate export. Original commits/files remain in the private byte-exact archive; the main archive index records original-to-published commit mapping. Models and raw run evidence remain external.
