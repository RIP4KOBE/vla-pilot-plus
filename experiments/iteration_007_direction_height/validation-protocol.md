# N7 independent validation protocol

Frozen before any N7 validation episode or validation implementation. N7's four exposed Dev originals are complete and independently audited: failures on tasks 0/3, successes on tasks 6/9, 2/4. The immutable Dev report is `artifacts/continuation_20260925/n7-dev-v1/full-dev-report-v1.json` and its SHA256 is recorded in the validation plan. This meets the preregistered numerical and native activity gates for validation eligibility; it is not independent performance evidence. The candidate algorithm, hyperparameters, Stage, model, action contract and physical GPU3 runtime remain frozen from N7 Dev. Validation code may only add plan, execution, audit and reporting logic, without changing scientific behavior.

Use the already frozen seed-plan blocks `validation_c1_b1` and `validation_c1_b2`, each covering the backend's exact ten task identities. For each task and each block, run one original episode for each of C0 (same-round P2 control), Q0 (starting QD), and N7, in that fixed arm order, for 60 originals total: 20 per arm, with exactly two distinct seeds per task. Source task/seed/init row fields from the frozen seed plan by task ID, never by positional zip. Verify no `(task_id, seed)` overlaps earlier exposed results or the formal set before release. The init-state row is unchanged across the two seeds per task; claim seed robustness only, not new-layout generalization. All three arms use the same runtime, task cache, input binding, 720-step cap, transport180 and physical GPU3. C0 has QD off by design; Q0/N7 retain the same 176/11 full guided chunk search budget. Preserve exact source/profile/runtime/model/BDDL/init/guidance fingerprints.

Run one worker and one original episode at a time; native evidence and task/result association must pass before dispatching the next. A legal task failure counts as failure and cannot be rerun. A failed audit or invalid infrastructure attempt stops this release, preserves all terminal and accounting evidence, and requires a separately frozen continuation for any narrowly eligible recovery. This release has at most 60 original dispatches and 14.0 GPU hours of GPU-process time. Each admission reserves the 1800-second timeout plus 40-second cleanup bound, respects the private 240-attempt/48-hour limit and preserves the 10-hour formal reserve. All originals charge the protected validation bucket; no Dev or formal row is authorized here. If a cap is hit before all 60 accepted cells, report validation incomplete rather than computing a selective score.

Before results, freeze the numerical gate: N7 must succeed in at least 10 of its 20 validation episodes and have at least as many successes as C0 and Q0 on their matched 20 episodes. Disclose all 60 task/block outcomes, gained/lost comparisons, failures, wall time and complete cohort accounting. The candidate must also pass native descriptor/cell/parent/selected-action audit and 176/11 compute checks wherever guided, with no additional projector/model/reward calls from the descriptor. If validation fails, N7 is not promoted to formal. If all gates pass, formal remains separately closed until its complete candidate/control/ablation plan and identities are frozen. No result-driven seed selection, threshold change or rerun is allowed.
