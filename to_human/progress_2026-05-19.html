Goal

Integrate RDT-1B fine-tuned on LIBERO Object into the VLS steering pipeline as a third policy (policy.type=rdt), with FKD particle resampling and VLM-guided gradient steering.

Root Cause Found & Fixed

Bug: Wrong action indices extracted from 128D unified state.

The code was using ManiSkill joint indices [0-6, 10] (Franka absolute joint positions) but the LIBERO-Object checkpoint was fine-tuned with EEF indices [30-35, 10] (end-effector position + rotation + gripper).

This caused arm actions to be ≈0.0004 magnitude — effectively zero — because the LIBERO checkpoint never learned to populate the joint-position slots in the 128D space.
