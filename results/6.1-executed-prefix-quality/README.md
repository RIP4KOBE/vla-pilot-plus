# N2 implementation and CPU validation

Status: implementation and CPU validation only. No N2 Dev result, recorded-candidate Q8 result, GPU/model deployment, or online score exists in this delivery. Arbor node 6.1 is not complete. The frozen preregistration remains `experiments/iteration_002_executed_quality/protocol.md`; root owns the source/input freeze and any subsequent evaluation.

The only new configuration is `main.eds_config.qd_quality_mode`, default `provider`, opt-in `executed_prefix_v1`. The primary profile retains sparse Q0's XY archive and original switches. The dual-quality transport also supports archive-off ED so a future separately authorized QD ablation can keep the same objective. This adds no Dev arm.

`core/qd_executed_quality.py` recognizes the complete preregistered singleton weighted-distance source AST, with generic nonnegative target index and alpha-renamed locals/function names. It compares the actual original function's compiled code structure, loader wrapper code/closure, and the relevant original globals. Compilation does not execute the provider. Code comparison does not use marshal's string-interning byte markers. Missing or unsupported source/binding is a pre-search provider fallback with an explicit reason; a changed contract after recognition, numerical error, or changed canonical action association raises. No task/seed/stage/path/result dispatch or default target exists. This deliberately restricted recognizer does not certify arbitrary equivalent Python programs.

The pure API is `executed_prefix_quality(projected_xyz, keypoints, *, target_index) -> Tensor[B]`. Inputs are the original native `(B,9,3)` projected t0..t8 and `(K,3)` keypoints with matching dtype/device. Output dtype/device matches the projection; no precision override exists. The helper uses t1..t8, weights `[1,1,1,1,1,3,3,3]/14`, and the original norm/square/FP32 scalar-weight/reduction sequence per candidate, then casts to native quality storage. Exact stored equality defines a tie; this helper performs no selection. Invalid finite/shape/index/dtype conditions fail explicitly. No projection/provider/model/simulator call is made.

Only canonical initial and terminal rollout scoring receive the explicit quality contract. Existing `_score_particles` supplies its already computed full projection through a local optional output. Auxiliary initial/renoise/rollout pretests and gradient calls retain provider semantics. Each canonical call preserves the old raw aggregate and a detached action-identity copy; validation rejects altered/reordered actions before archive insertion. Archive entries retain raw reward with the actual winning occurrence, without fingerprint lookup. Final Stage normalization receives the selected raw value and raw population vector. Archive extraction preserves the old Python-float to FP32 container path; archive-off keeps the final native population dtype. Original provider and aggregate records remain distinct from new internal quality records.

There is extra scalar arithmetic, source/code validation, an action-identity tensor copy per canonical batch, and dual-channel trace storage. These costs are not advertised as free. There are no added projector/provider/model/simulator calls. The 176 candidate/11 batch gates, eight-action decoder/executor and default-off algorithms are unchanged. The internal archive best/tie invariant now applies to declared Q8 only when active; no old-raw maximum retention is promised.
