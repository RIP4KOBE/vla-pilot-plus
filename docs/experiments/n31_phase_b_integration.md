## Placement and existing computation

Main reuses the cached raw reset observation and subsequent adapter.step returns. The independently named N31 packet copies raw EEF, xyzw quaternion, gripper qpos, raw keypoints and existing passive tracker identity. The passive tracker snapshot is enabled for N31 even when the recorder is off; no additional tracker position read, observation query or simulator step is added. The processed policy observation is not the proprioception source. Adapter._get_raw_obs is never called.

At each guided decision the policy starts a new bounded canonical cache. _observe_eds_score_call stores role/iteration independently of the recorder. _eds_score_population_as_cost reuses its existing _score_particles projection, requesting the already-acquired controller source origin through origin_out. It caches original full_trajs[:,1:9], eight outcome positions, while the provider's existing eds slice [1:8] stays seven points. No extra projection/provider call computes this cache. Native plans, projections, raw rewards/costs and source/cast origins are detached copies; current raw observed grip_site is separately named and is not asserted equal to controller origin.

Before each iteration's allocation/renoise, the ordinary archive select_global_best supplies the source identity. Match source_iter + fingerprint + exact native bytes within that decision. A unique canonical occurrence is identified when possible; duplicates must agree in projection, quality/cost and source/cast origins. Multiple agreeing occurrences remain explicitly ambiguous in origin, never chosen by favorable geometry. At most176 canonical occurrences/11 batches and10 opportunities exist. Auxiliary pretest/diagnostic calls cannot enter the cache. Provider binding and native keypoints are rechecked; reset/Stage/guidance changes and fresh decisions discard the session.

All original rollout denoising, random, RBF and mask operations complete on16 rows. Both the RBF and baseline methods then consume the prepared opportunity immediately before their sole original canonical score. The existing fallback goes through that same baseline method, so a proposal is consumed once. Only a changed proposal substitutes row15. Original initial16 and the other15 offspring are preserved at that boundary. Existing final_population and rollout_final trace refer to the scored composed batch, avoiding an extra diagnostic score. Normal archive/parent/final policies can reject and not select the proposal.

## Missing context and strict failure boundaries

Missing raw target/proprioception/tracker or unsupported provider yields a declared skip. Contradictory native provenance, malformed/nonfinite supplied observation, changed provider/target, wrong mask or conflicting duplicate content fails closed. Only the original score short-circuit caused by absent keypoints/provider can lack a canonical projection; it is recorded as Unknown_original_score_short_circuit and cannot create a proposal. With a recognized semantic contract, missing projection is always an error. This permission is passed from the real score call condition, not inferred merely from a missing field.

Actual old/off/on synthetic chains establish: empty provider with valid keypoints is legal Q0 and N31 preserves outputs, RNG and scientific/projection counts; an unsupported but nonempty provider scores normally and N31 skips; keypoints=None was already rejected by Q0's descriptor. N31 does not broaden the scientific input domain for that last case. A failed test demonstrating the pre-fix empty-provider regression is retained.
