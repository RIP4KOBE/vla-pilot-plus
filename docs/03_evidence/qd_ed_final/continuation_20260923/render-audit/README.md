## Concrete resource and GL differences

Installed version metadata reported MuJoCo **3.7.0**. Frozen dependency `robosuite/utils/binding_utils.py` SHA256 `8a1d052ceaffdc273b7643fe3f49d727c7f5f1f9061abecbab51bd631d113131`; `robosuite/renderers/context/egl_context.py` SHA256 `fc021027eb1d4917c71a30463ac0b1333baa907cfda5587b40e016c6f88ad31a`.

The installed MjRenderContext constructor creates a GL context, makes it current, calls sim.forward, creates MjvScene/camera/options/perturb objects, then constructs MjrContext and binds its offscreen buffer. Ordinary MjSim.render holds its original lock through context.render and read_pixels, sets the requested camera ID, calls mjv_updateScene, mjr_render, and mjr_readPixels. Reconstructing only native resources skips forward and scene/camera creation but **does create fresh textures, shadow/offscreen buffers, meshes/display lists and OpenGL context-local state**. Preserving Python scene identities does not preserve those resources or GL state. The 640×480 dimensions at render 6 exclude the known 640×640 resize as its direct trigger.

Installed EGLGLContext retains its process-global EGL_DISPLAY, creates an unshared EGL context with EGL_NO_CONTEXT, calls eglReleaseThread during construction, and uses its original make_current. The helper therefore does not reinitialize the global display, and is not a backend switch. Its retirement observation confirms only its recorded native calls; it is not a complete check of GL render correctness.

Official MuJoCo 3.7.0 source was inspected without loading MuJoCo. `mjr_makeContext_offSize` sets pixel packing/fog, creates offscreen/shadow/material/texture/geometry/font resources and binds buffers. `mjr_render` performs its own initLights/initGL3, camera setup and rendering passes. This identifies an auditable distinction between fresh-resource state and an already-rendered state, but no specific omitted GL initialization has yet been proven. In particular, this audit does not prescribe arbitrary glFinish, make_current, disabling shadows, changing multisampling, skipping the first image, or relaxing equality. Official source inspection is not proof that the installed binary was built byte-for-byte from the inspected tag.

Official references: [context construction](https://github.com/google-deepmind/mujoco/blob/3.7.0/src/render/classic/render_context.c), [3D rendering](https://github.com/google-deepmind/mujoco/blob/3.7.0/src/render/classic/render_gl3.c), [pixel readback](https://github.com/google-deepmind/mujoco/blob/3.7.0/src/render/classic/render_gl2.c).
