# Minimal static GL/CUDA control

This is a prospective engineering diagnostic, not an episode or algorithm evaluation. The controlling protocol is `experiments/iteration_001_execution_intent/gpu3-minimal-gl-cuda-control.md`. No GPU execution was performed while implementing or CPU-testing these artifacts.

`minimal_gl_cuda_worker.py` creates one 96×96 context using the exact installed robosuite `EGLGLContext` source, loaded directly to avoid robosuite package/environment initialization. MuJoCo package imports are allowed, but no `Renderer` instance, LIBERO, robot environment, RDT, large weights, provider call, or network request is used. One `mj_forward` initializes static transforms; no integration step is called. The XML has only a plane, box, light and fixed camera.

The worker imports torch and verifies `cuda.is_initialized()` remains false through both baseline frames. It then runs explicit CUDA initialization, a deterministic 32×32 float32 allocation filled with ones, and 32×32 matrix multiplication (independent expected result: all 32). Each boundary has exactly two render/readback calls, eight total. CUDA synchronization and CPU output checking are part of the allocation/matmul boundaries. Actual logical CUDA0 UUID is queried only after explicit initialization and must equal physical GPU3's frozen UUID.

Raw unflipped RGB uint8 and raw depth float32 arrays are saved before adjudication. Every frame records lossless NPY SHA256, raw-byte SHA256, shape, dtype, finite status and comparison to the first baseline. Before any GPU result, the contract fixes a nonblank baseline requirement: at least two distinct RGB **pixel colors** (not merely two channel values), spatially varying depth, and at least one depth value strictly between zero and one. All frames must have finite depth within [0,1]. These exact checks reject constant black, constant red, constant-depth and clear-buffer endpoint-only baselines. The parent independently rechecks them from the raw files. Any RGB difference, including between the first two frames, stops immediately with failed arrays preserved. Depth equality is recorded without becoming a pass requirement. There is no warmup, extra render, empirical threshold, adjustment or automatic retry. Native crashes retain the last JSONL phase boundary and faulthandler stacks when available. The XML's contrasting plane and box and their camera visibility are checked analytically on CPU; that check cannot prove native rendering succeeds, which is why the runtime nonblank gate remains mandatory.

`supervise_minimal_gl_cuda.py --plan` only reads and hashes files and git metadata, then writes a unique CPU contract directory. It never calls NVIDIA tools or imports GPU libraries. `--run` always creates a separate fresh contract; it does **not** consume or reuse a plan contract. Use `cpu-plan/` for CPU planning and `runs/` for dispatch outputs. Each contract is bound to its creating supervisor PID, and the worker rejects a different parent before loading dependency libraries. `--run` holds the shared runner lock, reconciles journals, requires GPU3 alone to remain idle for 120 seconds, checks existing recovery budgets and protected 14h/10h reserves, refreshes context-free EGL metadata, and checks both compute and graphics process isolation. A separate watchdog sends SIGKILL only to the still-running owned child group at the 120-second deadline, even if a metadata query blocks; completed children cannot falsely time out during parent evidence validation. All lifetime and cleanup are accounted in the GPU healthcheck ledger. Scheduling/reaping latency can make recorded elapsed time slightly exceed the deadline; no additional useful work is admitted. The child installs a Linux parent-death SIGKILL guard. If termination cannot be confirmed, the resource stays inflight for explicit reconciliation rather than being falsely completed. Success and failure terminal records hash available arrays, JSON/JSONL and native logs. A failure to write the supervisor summary still attempts the append-only cost journal.

The runtime manifest is independent and explicitly marks `cuda_egl_verified: false`: context-free metadata is not passed off as an old successful native probe. It freezes fresh boot ID, source HEAD, protocol, both scripts, XML, relevant runner helpers, Python, installed dependency metadata and relevant native libraries. It hashes no unused model checkpoints. Before dispatch it rechecks these fingerprints and the current physical3/EGL0 association. Production context selection is inferred from the exact installed implementation plus the explicit EGL index and fresh enumeration; no additional display-device identity query is inserted into this minimal interaction test. Consequently a pass is evidence for this small path only, not proof that the application's production display or RDT path is healthy.
