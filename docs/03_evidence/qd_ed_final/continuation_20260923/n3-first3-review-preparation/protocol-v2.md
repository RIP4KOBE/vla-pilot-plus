## Fixed analysis over every guided N3 decision

Join metric global_step to exactly one decision_context and the recorded source-mode/feedback_selection. All recognized, inapplicable, inactive and active rows remain in output. Applicable and active are distinct. Require native specialized audit schema `n3-native-feedback-audit-v1`, exact checked/active counts, previous full8 actual acknowledged prefix and identity/registry continuity through the existing gate. No inference from scalar changed-candidate counts.

For each **active** decision, use every canonical initial/offspring batch in fixed iterations -1..9, each16 rows. Associate native samples and raw/internal qualities exactly with the existing scoring_inputs/aggregate/effective_quality of that canonical iteration, preserving dtype, shape and bytes. These are the vectors actually passed into the frozen QD archive updates; this is established by the bound source, not a replay. Record candidate native fingerprints (shape and dtype included), native raw/internal values, all equal-value rank groups, and all unordered pair comparator transitions in {-1,0,+1}². All canonical pair changes are descriptive only: within-cell archive ranking does not necessarily compare cross-cell candidates, and the sparse parent plan can use identity indices. Retain strict reversals, tie splits and tie merges without using them to pass activity. These records do not prove a changed retained parent, archive replacement, future proposal stream or physical outcome.

Require exactly11 unique-iteration canonical scoring records and exactly10 unique-iteration archive/ED parent records, with no dictionary overwrite of duplicate occurrences. The recorded order must be previous canonical batches < archive allocation < parent allocation < next scoring inputs < aggregate < effective quality < canonical batch; the initial scoring triple also precedes its canonical batch, and final selection follows all canonical batches. Check all10 recorded archive parent allocations and parent_allocation returns have16 slots, native source rows drawn from earlier canonical iterations with matching original/internal quality values, and actual index/count identities. Preserve all slots and ties. Do not invent unique insertion ancestry, recompute ED probabilities, rerun allocation or attribute a changed slot to feedback without a recorded direct comparison.

For the recorded final pool, join every native action to its earlier canonical raw/internal pair. Require a unique native-value association; keep duplicate occurrences but never select an arbitrary conflicting association. Preserve the existing FP32 archive container of original native scalar values. Require selected index/native action/selected raw and internal values, internal maximum membership, and metric raw gap agreement. Report all tied raw maxima and all tied internal maxima. An actual selected raw value **strictly below** the same final pool's maximum raw value is a tie-robust final-selection witness: the executed selection is outside every raw maximizer. No claim is made about the pool that a different search would have generated.

The actual final consumer is QDArchive.select_global_best, which orders all current archive entries by (-reward, fingerprint, cell); the recorded final population is exactly that archive pool. Record all final-pool raw/internal comparison transitions and ties, but the alternative ordering witness is narrower: compare only the actual selected entry to each different native competitor. Require selected membership in the internal-max set. A change in the selected-versus-competitor quality comparator (strict reversal, tie split or tie merge) establishes a changed reward preference/tie relation used by this global final-selection consumer. It does not by itself establish a different executed action, including when fingerprint/cell tie breaking returns the same selection. Pair changes involving only two nonselected entries cannot pass, and a singleton pool cannot supply this alternative. Preserve every duplicate occurrence but exclude same-native pairs from a witness.

Search activity passes if at least one actual active decision has either this selected-relative final-pool ordering witness or the strict final-pool raw-gap witness. Report every active decision and aggregate all such evidence, not only the first or best witness. No performance qualification, task/seed branch, fitted tolerance or after-outcome window selection. Comparisons use exact finite recorded native values; subtraction is not used to decide order/ties.
