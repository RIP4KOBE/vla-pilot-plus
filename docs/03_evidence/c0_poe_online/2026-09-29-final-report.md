## 3. 为什么没有直接恢复历史 Gemini-2.5

新凭据调用当前 Gemini-3-Flash 的真实生成请求成功返回 `OK`，后续 181 次在线多模态 Stage 也成功。因此本次不是新密钥失效。

历史 Gemini-2.5-Flash 的四次生成探测均返回 HTTP 500，包含原始双图请求、最小文本及名称大小写检查。Poe 当前模型目录没有该原模型，其[官方页面](https://poe.com/Gemini-2.5-Flash)显示 `Gemini-2.5-Flash_DEPRECATED`、`PRIVATE`。Poe 的[兼容接口说明](https://creator.poe.com/docs/external-applications/openai-compatible-api)说明私有 bot 不受支持。这些证据支持“历史模型在本次 Poe 接入中已不可用”，不能靠换一把可用密钥恢复相同服务。

模型目录 HTTP 200 本身不能验证密钥，因为[目录接口无需鉴权](https://creator.poe.com/api-reference/listModels)；本报告依据的是实际生成成功和本轮完整 Stage 请求。服务器现有代理可访问 Poe；直连不可达，但不阻碍通过现有代理完成实验。没有更改服务器代理配置。

## 6. 后续建议与边界
